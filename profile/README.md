## Noden — SSH, SFTP & AI for macOS

[Noden](https://nodenapp.com/) is a native macOS SSH client with saved connections, multi-session terminal grids, a dual-pane SFTP file manager and an optional AI command assistant. Commands proposed by the assistant are shown for approval before execution.

- [Noden website and direct download](https://nodenapp.com/)
- [Official Noden GitHub repository](https://github.com/useroamteknoloji/noden)
- [Noden 1.0 release](https://github.com/useroamteknoloji/noden/releases/tag/v1.0.0)
- [macOS SSH client guide](https://nodenapp.com/macos-ssh-client.html)
- [MobaXterm alternative for Mac](https://nodenapp.com/mobaxterm-alternative-for-mac.html)

Install Noden with Homebrew:

```bash
brew install --cask useroamteknoloji/tap/noden
```
